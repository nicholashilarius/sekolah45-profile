# Website Profil SMK Rakyat 45

Template statis responsif untuk prototipe UTS Sistem Terdistribusi.

## File
- `index.html`: struktur dan konten website.
- `style.css`: desain responsif untuk desktop dan ponsel.
- `script.js`: navigasi mobile dan tautan PPDB.

## Menjalankan
Ekstrak ZIP, lalu buka `index.html` di browser. Bisa juga gunakan Live Server di VS Code.

## Sebelum dipublikasikan
- Kontak, alamat, jadwal, program keahlian, dan sebagian konten adalah contoh/fiktif. Sesuaikan dengan data yang benar dan diizinkan.
- Setelah portal berita Blogger dibuat, isi `NEWS_URL` pada `script.js` dan tambahkan tombol/tautan portal berita sesuai URL tersebut.
- Setelah halaman PPDB dipublikasikan, isi `PPDB_URL` pada `script.js`.
- Website ini belum di-host dan belum terhubung ke domain. Domain utama dan subdomain perlu dikonfigurasi setelah layanan diterbitkan.
